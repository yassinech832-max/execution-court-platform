# منصة مختبر ياسين شامي للمرافعات والتنفيذ الجبري

نموذج منصة تعليمية تفاعلية منجزة من طرف **د. ياسين شامي**، كلية القانون، جامعة الإمارات العربية المتحدة.

## ما الذي يتضمنه النموذج؟

- محاكاة لمسارين: الدعوى التجارية من الصحيفة إلى التوزيع، والحجز التحفظي والإشكال في التنفيذ.
- محكمة افتراضية بأدوار: القاضي، المحامي، الخصم، المنفذ، وموظف التبليغ.
- مختبر تبليغ ينشئ محضراً افتراضياً ويختبر الهوية والوسيلة والأثر.
- غرفة تنفيذ تختبر السند التنفيذي والحجز لدى الغير والمنقولات والعقار.
- مساعد ذكي لتدريب صياغة صحيفة الدعوى وطلب التنفيذ والاعتراض ومحضر التبليغ.
- أيقونة «تحليل الأحكام المدنية» لتحويل نص الحكم إلى مسودة وقائع وإجراءات، وإشكال قانوني، ومنطوق، ومقدمة وعرض موضوعي وتقييم شخصي وخاتمة وفق منهجية التعليق على قرار.
- موسوعة الكتاب الإجرائي: فهرس تفاعلي للأجزاء الثمانية (350 صفحة مصدر، منها 348 صفحة نصية مستخرجة قابلة للبحث)، مع قواعد تدريبية ومقاطع أصلية مرتبطة بالمحاكاة والمحكمة والمساعد الذكي وتحليل الأحكام وبنك الأسئلة.
- موسوعة التنفيذ الجبري: فهرس مستقل للأجزاء السبعة (336 صفحة مصدر، منها 334 صفحة نصية مستخرجة قابلة للبحث)، يغطي السند التنفيذي، أشخاص التنفيذ، محل التنفيذ، الحجز والبيع، التوزيع، وسائل الإكراه، ومنازعات التنفيذ.
- سجل تشريعي لقانون الإجراءات المدنية: الدفعة الأولى من المواد (1–49) بالنص المرفق، مع فهرس للأبواب والكلمات المفتاحية، قارئ حرفي للمادة، بحث برقمها أو موضوعها، وروابط مباشرة إلى المحاكاة والتبليغ والمحكمة والمساعد الذكي والاختبارات والخريطة.
- بنك أسئلة تكيّفي يضيف سؤال معالجة عند الخطأ ويعرض نقاط الضعف التعليمية.
- خريطة ذهنية/انسيابية لمسار الدعوى والحجوزات وفروع الإشكال.
- خريطة مصادر تربط المحطات بالمادة القانونية والموضع التعليمي في الكتابين.
- مرجع تربوي داخل المسار: «التعليق على قرار: منهجية وتطبيق»، مجلة المعرفة، العدد 14، مارس 2024، ص 421–428.
- حفظ تقدّم الطالب محلياً في المتصفح، دون تسجيل دخول أو تخزين بيانات شخصية.

## التشغيل المباشر

يمكن فتح `index.html` مباشرة في المتصفح. ستعمل كل وظائف المحاكاة والمساعد الذكي بمحرك تدريبي محلي داخل المتصفح.

## تشغيل الخادم الاختياري

يتطلب الخادم Node.js 18 أو أحدث:

```bash
node server.js
```

ثم افتح:

```text
http://localhost:4173
```

الخادم يقدّم الملفات الثابتة ويضيف المسار `POST /api/ai/coach`. إذا لم تضبط أي موصل خارجي فسيستمر المساعد بالعمل بمحرك التدريب المحلي.

## موصل ذكاء اصطناعي خارجي (اختياري)

لا تضع أي مفتاح في `index.html` أو `app.js`. عند الحاجة إلى موصل متوافق مع واجهة Chat Completions، شغّل الخادم مع متغيرات بيئة خاصة بالخادم:

```bash
AI_API_URL="https://example.invalid/v1/chat/completions" \
AI_API_KEY="ضع_المفتاح_في_بيئة_الخادم_فقط" \
AI_MODEL="اسم-النموذج" \
node server.js
```

الموصل يطلب JSON منظم، وإذا تعذر الاتصال يعود تلقائياً إلى المحرك المحلي. ينبغي للجامعة اختبار مزود الخدمة وسياسة الخصوصية قبل استخدامه مع أي بيانات حقيقية.

## حدود الاستخدام التعليمي

هذه منصة محاكاة وليست نظام محاكم أو بوابة تنفيذ رسمية. لا تُدخل أسماء حقيقية أو أرقام هويات أو مستندات قضائية حقيقية. الملاحظات التي يقدمها المساعد تدريبية وتحتاج إلى مراجعة عضو هيئة التدريس.

## أساس المحتوى

صُممت المسارات استناداً إلى الأجزاء الثمانية المرفوعة من كتاب «الوجيز في قانون الإجراءات المدنية» والأجزاء السبعة المرفوعة من كتاب «الوجيز في قانون التنفيذ الجبري»؛ أُدرجت خريطة كل كتاب وقواعده التدريبية والنص المستخرج صفحةً صفحةً، ثم رُبطت نتائج البحث بوحدات المحاكاة والصياغة والمحكمة والتبليغ وتحليل الأحكام والاختبارات وغرفة التنفيذ. أضيفت الدفعة النصية الأولى من قانون الإجراءات المدنية (المواد 1–49) في `civil-law-data.js` مع بصمة مصدر ووصلة النص الرسمي، ويظل النص المرفق مرجع الإدماج لهذه الدفعة. عند تحديث القانون أو إرسال دفعة جديدة يجب تحديث سجل المواد وقواعد السيناريوهات قبل استخدامها في مقرر رسمي.
